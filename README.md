# Movie Rating System

## Project Overview

The Movie Rating System is a Java program that allows a user to enter
their name and five movies they have recently watched. The user rates
each movie from 1 to 10, and the program stores the movie names and
ratings in parallel arrays.

The program calculates the average movie rating and uses decision
structures to respond to the user's ratings. It uses if-else statements,
nested if statements, logical operators, a switch statement, and the
conditional operator. It also validates ratings to make sure they are
between 1 and 10.

The program asks for the user's favorite movie genre and gives a response
and movie recommendation based on their choice.

## Reflection

A nested if statement places one if statement inside another, while an
if-else statement chooses between different conditions at the same level.
A switch statement can make code easier to read when one variable needs
to be compared against several specific choices. The conditional operator
simplifies basic decisions by allowing a short if-else operation to be
written in one expression. Short-circuit evaluation means Java may stop
checking a logical expression once the final result is already known.
This can make logical expressions more efficient and prevent unnecessary
conditions from being evaluated.
